# Included Orbit Revolution Files

This directory contains the Sentinel-3A, Sentinel-3B, and SWOT Orbit Revolution
Files used by the documented examples. Each text file contains dated pole,
equator, and pole events with cycle, pass, revolution, longitude, and latitude
information.

The files constrain the orbit interpolation used for acquisition screening.
They are not a replacement for precise orbit ephemerides or product-level pixel
geolocation.

Current files:

- `S3A_ORF_AXXCNE20260717_075300_20160302_154759_20260801_081654`
- `S3B_ORF_AXXCNE20260717_080700_20181123_213005_20260801_080330`
- `SWOT_ORF_AXXCNE20260717_103800_20230720_200750_20260801_081502`

The timestamps embedded in the filenames identify the table generation time and
the covered event interval.
